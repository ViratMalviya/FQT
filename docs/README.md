# Project Documentation

This directory contains supplementary documentation for the FQT (Federated Quantum-Train) framework.

## Mini Project Report

The full Mini Project Report covering the system design, experimental setup, results analysis, and literature review is available upon request.

**Report covers:**
- Problem formulation: audio deepfake detection under privacy constraints
- Quantum-Train architecture: VQC weight generation theory and implementation
- Federated learning setup: Flower simulation, FedAvg convergence analysis
- Results: 84.62% accuracy on ASVspoof 2019 LA partition (5 rounds, 3 clients)
- Comparison with centralized baseline and classical CNN-only approaches
